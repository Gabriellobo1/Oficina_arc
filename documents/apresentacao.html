Visão geral

🔧 O que é o projeto?

Um sistema web completo que organiza a rotina de uma oficina mecânica: cadastra clientes e seus veículos, abre ordens de serviço, registra os serviços feitos e as peças usadas, controla o estoque, recebe o pagamento e coleta a avaliação do cliente.

👥 Quem usa

Atendentes e gerentes da oficina, cada um com seu nível de acesso.

🎯 Para quê

Trocar o controle em papel/planilha por um sistema confiável e organizado.

📊 O que entrega

Histórico do veículo, faturamento e desempenho da oficina num clique.

Objetivo

🎯 Objetivo do projeto

Colocar em prática o conteúdo de Banco de Dados II, construindo um sistema real apoiado num banco de dados bem organizado.

  • Modelar uma situação real (uma oficina) em tabelas
  • Escrever o banco e as consultas na mão, em SQL
  • Conectar as tabelas de forma correta e organizada
  • Manter os dados confiáveis e sem informação perdida
  • Deixar o sistema rápido mesmo com muitos dados
  • Tirar relatórios úteis a partir das informações guardadas

Backend · resumido

⚙️ O servidor que conversa com o banco

É a "ponte" entre a tela e o banco: recebe os pedidos do usuário, confere se está tudo certo e busca ou grava os dados no banco.

  • Feito em Fastify (Node.js)
  • Toda comunicação com o banco é em SQL escrito à mão
  • Login seguro com senha criptografada
  • Confere os dados antes de salvar (evita erro)

O caminho de um pedido

Usuário clica na tela →
servidor recebe e confere →
busca/grava no banco →
devolve a resposta pra tela

Como tudo se conecta

🔗 As tabelas conversam entre si

O segredo de um banco relacional é ligar as informações. Em palavras simples:

👤➜🚗
Um cliente pode ter vários carros
🚗➜📋
Um carro pode passar por várias visitas à oficina
📋➜🔧
Cada visita (OS) tem os serviços feitos e as peças trocadas
📋➜💳
No fim, cada visita tem um pagamento e uma avaliação
Assim ninguém precisa digitar o mesmo dado duas vezes — o cliente é cadastrado uma vez e fica ligado a todos os carros e visitas dele.

Dados confiáveis

🔒 Como garantimos que nada se perde

O banco tem regras automáticas para os dados ficarem sempre certos, sem depender da memória de ninguém:

🆔 Sem duplicar

Cada cliente, carro ou serviço tem um código único. Não existem dois iguais nem e-mail/placa repetidos.

🛡️ Histórico protegido

Não dá para apagar um cliente que ainda tem carros ou serviços ligados a ele. O histórico fica preservado.

💰 Valores exatos

Preços e pagamentos são guardados com precisão, sem erro de centavo no troco.

📦 Estoque automático

Quando uma peça é usada numa OS, ela sai do estoque sozinha — sem ajuste manual.

O resultado

📊 O que o banco consegue responder

Como tudo está organizado e conectado, o sistema responde perguntas do gerente na hora:

💵 Quanto faturamos no mês?

Soma todos os pagamentos do período.

🏆 Quais serviços mais saem?

Ranking dos serviços mais pedidos.

⭐ Quem são os melhores funcionários?

Nota média e atendimentos de cada um.

⚠️ Quais peças estão acabando?

Avisa quando o estoque fica baixo.

É isso que diferencia um banco de dados de uma planilha: ele não só guarda — ele responde perguntas e ajuda a decidir.
